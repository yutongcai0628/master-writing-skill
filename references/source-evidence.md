# 后台来源记录

## 目的

后台来源记录用于核对引文、位置、说话者和方法判断。它只用来保证质量，默认不给读者看。

## 单条记录格式

```text
编号：E-001
位置：第 3 章 / 第 42 页
谁说的：作者写的 / 本人说的 / 旁人说的 / 文件材料 / 译者注
短引，或者用自己的话准确转述：……
这段干什么：开头 / 推进 / 转折 / 举证 / 反驳 / 收尾
看的是哪一层：词 / 句 / 节奏 / 素材 / 结构 / 评论
支持的方法：……
跟用户目标的关系：高 / 中 / 低
引用方式：短引 / 转述 / 只在内部分析用
```

## 使用规则

- 扫描全书时建立内部记录；
- 每张卡直接标出处，例如「第 3 章｜作者写的」；
- 总结出的主要结论，至少要有两个不同位置撑着；
- 只出现过一次的现象，标成「局部技巧」；
- 用户问依据时，给章节和必要的短引；
- 用户明确想看全部出处时，再在同一篇文档末尾整理一张简单的来源表；
- 定位不到章节或页码就明说。
