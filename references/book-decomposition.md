# 一本书或长文怎么扫，段落怎么挑

这一步同时产出两样东西：**给读者看的章节表或文本地图**，和**只给自己用的候选清单**。

## 一、逐章或逐单元扫

每章或每个文本单元记四件事：

- 这一单元讲了什么，核心的矛盾在哪
- 开头、转折、场景、细节、原话、评论、结尾分别在哪
- 谁在说话：作者写的 / 本人说的 / 旁人说的 / 文件材料 / 译者注
- 这一单元在写法上做了什么值得学的动作

**第四条要当场写成一句话，直接进章节表或文本地图。** 表是给读者看的，做法见 [`chapter-map.md`](chapter-map.md)。边扫边写，别等扫完再回头补；表里缺单元就说明全文还没扫完。

前三条留在候选清单里，**不进用户文档**。格式见 [`source-evidence.md`](source-evidence.md)。

## 二、候选段落怎么筛

四条标准：

| 标准 | 问自己 |
|---|---|
| 一眼能看出作者在干什么 | 读者能从具体文字里看见这个动作吗？ |
| 位置重不重要 | 它负责开头、推进、转折、举证还是收尾？ |
| 对得上用户的目标吗 | 它能直接用在用户想提升的那类写作上吗？ |
| 有没有补上新东西 | 换了新的章节、新的说话人、新的材料类型或新的作用吗？ |

**做几张卡由用户的水平决定，规则只在 SKILL.md 的水平表里，这里不重复。** 覆盖开头、中间和结尾，别从同一处连着摘。

## 三、摘多长

三种：单句、几句（2–4 句）、整段。配额和「掐一句试试」的判断方法都在 [`close-reading.md`](close-reading.md)，那里是唯一的出处。

值得摘的段落包括：

- 一句压得很紧的判断
- 让人想读下去的开头句
- 让人物现身的动作或原话
- 让读者改变看法的转折句
- 把事实压成一个画面的收尾句
- 一个动作完整的短段落

挑的时候看两件事：能不能教会人，以及这个作者的辨识度在不在里面。

## 四、拆完之后再总结

卡片做完后，回头找跨章节反复出现的选择：

- 作者怎么进入一个人或一个问题
- 场景、背景、原话、评论怎么交替
- 句子怎么控制远近和快慢
- 结尾怎么改变前面所有材料的意思
- 同一招在哪些地方好用，在哪些地方显得过了

总结时看 [`style-dimensions.md`](style-dimensions.md) 的检查清单。结论统一放进「从这些卡里能总结出什么」那一节，别在别处重复。

## 五、从头到尾怎么做

```text
逐章或逐单元扫（边扫边写章节表或文本地图）
→ 按用户目标筛候选段落
→ 一张一张做卡
→ 从卡里总结
→ 怎么用到自己的稿子上
→ 练一下
```
