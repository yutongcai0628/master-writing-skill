# 飞书文档模板

标题：`《书名》× 想提升的写作类型`

## 只交付一篇文档

全书拆解、句子卡、练习、方法选择入口和完整章节表都放在同一篇主文档里。长书可以把完整表移到文末的“按需查阅”部分，仍然只给读者一个飞书入口。不要创建第二篇文档、子文档或第二个交付链接。

编号首次出现时解释一次：`M` 是 Method（方法），`C` 是 Card（拆句卡）。后文统一写“方法 M01”“拆句卡 C01”，中文名称放在编号前面。

## 一条原则：写给读者看

文档里**不出现我们怎么干活的**。摘取配额、掐一句试试、候选清单打分这些是我们的方法，用户不需要知道，写进去只会让人以为要先学一套东西才能开始读。

判断方法：**这句话是在帮读者学写作，还是在解释我们的流程？** 后者删掉。配额和引用比例这类自查数字，用聊天消息告诉用户。

## 别让用户面对一整屏文字

这是最容易劝退人的地方。硬性要求：

| 手段 | 用在哪 | 要求 |
|---|---|---|
| **表格** | 卡片正文、章节架构、怎么用的清单 | 卡片正文一律用表格，不写成七段话 |
| **高亮框** | 每一组的开头、开头说明、练习入口 | 一到两行，说清这一组在讲什么 |
| **画板** | 第一步固定三张，第二步按组判断 | 有清楚步骤或关系就画；只有单句、画出来只会重复文字时省略 |

- 一段控制在 3–5 行，超过五行就拆开或改成表格
- 连续两屏纯文字就是排版失败
- 每张卡之间留清楚的空隙

## 篇幅分配

| 部分 | 占比 |
|---|---:|
| 开头说明 | 2% |
| 第一步 · 拆整本书 | 25% |
| 第二步 · 拆句子 | 55% |
| 怎么用到你自己的稿子上 | 8% |
| 练一下 | 10% |

文档末尾再放一个两行以内的“保存成个人写作训练 Skill”入口，不另占主要篇幅。

## 文档顺序

### 1. 开头说明

一个高亮框，两行以内：书名作者、这次要提升什么。不解释方法。

### 2. 第一步 · 拆整本书

四样东西，画板为主、文字为辅：

- **这本书在讲什么**：三五句话说清主旨和全文反复追问的问题，配画板一
- **章节或文本架构**：画板二画出全文分几个阶段、怎么推进；后面跟章节表或长文文本地图
- **核心写作手法**：画板三展示作者反复用的 4–6 个招数
- **这本书的文字特点**：并进画板三，写清句子长短、用词习惯、本书里很少出现的写法；译著要标明译者和版本

章节表或长文文本地图按 [`chapter-map.md`](chapter-map.md) 做。

超过 30 个章节或文本单元时，正文只放阶段地图和代表单元；代表表继续使用“章 / 文本单元、讲了什么、写作看点、对应拆句卡”四列。完整表放在同一篇文档末尾。正文给出“可跳到文末查阅”的文字提示，不创建外部入口。

### 3. 第二步 · 拆句子

按写作动作分组，每组 3–4 张卡。每组先判断有没有清楚的步骤或关系：

```
高亮框（一到两行，这组在讲什么）
画板（可选；有步骤或关系时画）
卡片 × 3–4
```

每张卡的样子：

```
### 拆句卡 C07 ｜ 招数的名字（动作式）
[摘了多长] ｜ 第 X 章 ｜ 作者写的 / 本人说的 / 旁人说的 / 文件材料 / 译者注

> 原文引用

| 前情是什么     | …… |
| 用词和标点     | …… |
| 前后怎么接起来的 | …… |
| 放在这儿干什么 | …… |
| 可以学到哪一招 | …… |
| 我该怎么用     | …… |
| 什么时候别用   | …… |
```

原文用引用块，其余全部装进一张表。字段名照 [`close-reading.md`](close-reading.md)。

### 4. 怎么用到你自己的稿子上

一张表。左列动作，右列具体做法。每条都要能今天就做。

### 5. 练一下

一份素材包（不必重开原书就能完成）、一道 8–15 分钟的题、3–4 条自查、一个交作业的入口。素材包用列表，题用有序列表，自查用无序列表。

### 6. 保存成个人写作训练 Skill

放一个高亮框，列出 4–6 个方法编号和动作式名称，写成“方法 M01｜动作名称”，邀请用户回复至少 3 个编号，或直接回复“全部”。完整生成规则见 [`personal-coach-skill.md`](personal-coach-skill.md)。

这部分只提供选择入口。用户确认以后，在对话中生成独立技能包，不把四个子 Skill 引用文件塞进飞书文档。

### 7. 按需查阅 · 完整章节表或文本地图

超过 30 个章节或文本单元时，把一单元一行的完整表放在这里。标题直接说明“按需查阅”，让赶时间的读者可以停在方法选择入口。这部分仍在同一篇主文档里。

## 出处怎么标

章节和谁说的直接标在引文旁边。内部候选清单只用来核对，不进正文。用户明确要研究附录时再加来源表。

## 标题层级

- 一级标题：第一步、第二步这样的大块
- 二级标题：分组
- 三级标题：单张卡
- 表格装卡片正文
- 加粗只用在表格外的关键句上，别在表格里再加粗

## 交付前检查

- 有没有连续两屏纯文字？
- 每个字段名能不能对着朋友说出口？
- 有没有先否定一种说法、再转向另一结论的对比句式？顺序颠倒的变体也要检查
- 卡片正文是表格还是段落？段落就重排
- 文末有没有给出个人写作训练 Skill 的方法选择入口？
- 飞书交付是不是只有一个文档入口？
- `M`、`C` 首次出现时有没有解释，后面有没有带上“方法”“拆句卡”？
- 只有单句卡的组是否省掉了重复文字的画板？
