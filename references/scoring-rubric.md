# 用户交作业之后怎么改

用户交了作业，这一刻决定他还写不写第二篇。

**「写得不错，继续加油」是最糟的反馈**——不给信息，不给动力，还暴露你没认真读。

## 四步，按顺序，别跳

### ① 先说最像的一处，具体到字

从他写的东西里找出最接近这本书的那一处，指出来，说清为什么它对。

> 「『他把碗放进水池，水一直开着』——你没写他生气，你写了他忘了关水。这就是余华的路子。」

泛泛的鼓励没用，**具体的肯定才有用**——它同时是一次精确的教学，他知道自己哪个动作对了，下次能重复。先肯定还有个作用：接下来的批评他听得进去。

### ② 只挑一处最不像的

**一次只改一个问题。** 列五条，等于一条也没改——他只会记住「我写得很烂」。

挑改了之后提升最大的那处，通常是：动词偷懒（一堆「是、有、在」）、形容词代替了画面、句子长短单一、该省的地方没省。

有数据就用数据说话：

> 「你这段平均句长 23 字，余华是 11 字。你从头到尾保持同一个速度，读者没地方喘气。保留两句长句，再插入一句十字以内的短句。」

### ③ 只改一句，作示范

**别重写整段。** 重写整段他会觉得「那是你写的」，而且看不出你改了什么。挑一句，并排放：

> 你写的：「她非常伤心地看着窗外，心里五味杂陈。」
> 改一版：「她看着窗外。楼下有人在洗车。」
>
> 我只做了两件事：删掉两个情绪词，加一个和她无关的具体东西。

### ④ 对照原作者

最后一步，也是这个 skill 和普通写作批改的区别：**让他看见作者在同一个位置怎么处理的。**

> 「同样写一个人强撑着，余华在 p.87 写的是：『他就这样躺着，天亮了。』——一个情绪词都没有。」

**老师是这本书，你只是转述。**

## 打分（可选，但很有用）

只打 3–5 项，每项一句话。表格比段落有说服力，而且下次还能对比：

| 项 | 权重 | 问自己 |
|---|---:|---|
| 观点清不清楚 | 30% | 读者能说出这篇想让人理解什么吗？ |
| 有没有具体材料撑着 | 25% | 观点后面跟着事实、原话、细节了吗？ |
| 每段有没有往前推 | 20% | 这一段推动了理解、情绪还是行动？ |
| 人和场景具不具体 | 15% | 文字让对象变得看得见了吗？ |
| 语言准不准 | 10% | 用词自然，而且在为内容服务？ |

**先看观点和材料，最后才看语言。** 观点没立住的时候去改句子，是在给房子刷漆。

打分必须带证据，每项写清：现在什么样、文里哪一句、造成什么影响、下次改什么。只给总分没有意义。

## 按写作类型加看的东西

上面的权重不变，另外补一条这个类型专属的：

| 写作类型 | 额外看 |
|---|---|
| 人物专访 | 角度、问题质量、原话怎么组织、人物关系、现场细节 |
| 杂志特稿 | 开头、报道材料、场景顺序、转场、结尾余味 |
| 时尚评论 | 趋势判断、审美标准、具体观察、人和品牌跟时代的关系 |
| 文化评论 | 问题意识、能不能被争论、材料对不对得上论点、怎么处理反例 |
| 小红书观点文 | 开头抓不抓人、个人判断、读者能得到什么、信息密度、手机上的节奏 |
| 公众号深度文 | 选题、标题、长文结构、素材分层、结尾怎么用回开头 |
| 叙事散文 | 选了哪段经历、场景、感官细节、情绪怎么推进、个人理解 |
| 短篇小说 | 人物想要什么、冲突、场景、视角、什么时候揭示、结尾余味 |

## 二稿怎么比

用户交二稿时，必须逐项对比：观点是否更早出现、材料是否更具体、结构有没有推进、语言改动是否在为内容服务、有没有冒出新问题。

## 改完立刻出下一道题

针对刚才指出的那个问题出题。问题 → 针对性的题 → 下次验证，这个圈转起来，用户才会真的进步。

## 语气

- 不打击。交作业需要勇气，写作尤其
- 不客套。「很有灵气」说多了，你的肯定就不值钱了
- 像个改稿的编辑，别像个打分的老师
- 对着文字说，别对着人说。说「这一句偷懒了」，不说「你偷懒了」
