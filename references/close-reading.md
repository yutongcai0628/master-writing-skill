# 拆句子

从一段原文出发，让读者看见作者在用词、造句、组段、搭全篇这四件事上分别做了什么。

## 摘多长：按内容选择三种长度

「金句」这个词天然把人往「一句格言」上带。实际要摘的是**一个招数完整的那一段**，可能是一句，也可能是三句，也可能是一整段。

| 摘多长 | 长度 | 装得下什么 | 配额 |
|---|---|---|---|
| **单句** | 1 句 | 一句判断、一个定义、一句格言 | ≤ 30% |
| **几句** | 2–4 句 | 一次转折、一个完整动作、前后呼应、什么先说什么后说 | ≥ 40% |
| **整段** | 完整段（中间可省略） | 开头、转场、一个场景、收尾、几个人轮流说话 | ≥ 25% |

**配额是硬要求。** 交付前数一遍，单句超过 30% 就重新摘。

只摘单句会漏掉所有跨句子的招数。**一句话里看不出它在段落里干什么，也看不出它跟前后章节的关系。**对单句硬做这两层分析，只能写出空话。

## 摘到哪儿为止：掐一句试试

> **把前面那句或后面那句掐掉，这个招数还看得出来吗？**

- 看得出来 → 一句就够
- 看不出来 → 往外扩，扩到招数完整为止，一句不多一句不少

这一招同时防两件事：摘太短（招数残缺）和摘太长（变成抄书）。

### 这些招数，一句话装不下

一张卡只要打算讲下面任何一条，就得摘几句或整段：

- 关键信息故意押后说
- 从概括切到现场，或者反过来
- 前面提过的东西后面再用一次
- 几个人轮流说同一件事
- 节奏（句子长短的配比至少要三句才看得出来）
- 一段话怎么开头、怎么收尾
- 先摆材料还是先下结论

## 挑哪些来摘

优先挑：

- 负责开头、推进、转折或收尾的段落
- 什么先说什么后说明显是设计过的
- 动词准确、细节具体、形容词克制的
- 靠标点和长短句控制节奏的
- 把一个抽象判断压成动作、细节或画面的
- 能直接用在读者当前写作目标上的

覆盖开头、中间和结尾。别从同一处连着摘。

## 卡片长什么样

**原文用引用块，其余全部装进一张表。** 表格方便扫读。七段连续文字会让长文档更难读。

```
### 拆句卡 C07 ｜ 招数的名字（要像一个动作）
[单句 / 几句 / 整段] ｜ 第 X 章 ｜ 作者写的 / 本人说的 / 旁人说的 / 文件材料 / 译者注

> 原文引用

| 前情是什么     | 一句话交代这段之前发生了什么 |
| 用词和标点     | 哪几个字在起作用 |
| 前后怎么接起来的 | 一句话里的前后部分怎么安排；几句话之间怎么衔接、什么先说、什么后说 |
| 放在这儿干什么 | 在整篇里是开头、推进、转折、举证还是收尾 |
| 可以学到哪一招 | 给这个招数起个动作式的名字，一句话说清 |
| 我该怎么用     | 一个明天就能做的动作 |
| 什么时候别用   | 什么情况下会显得假、显得用力过猛 |
```

拆句卡编号从 C01 开始连续排列，交付后保持不变。文档第一次出现时解释 `C` 是 Card（拆句卡），后面始终带上“拆句卡”三个字。个人写作训练 Skill 会用这些编号指回原文证据。

### 三种摘法，重点不一样

字段一样，写的详略不一样。三种摘法不能平均用力。抠词在单句上最容易，平均用力会让每次拆解都退回单句。

| 摘多长 | 哪一栏写足 | 哪一栏一句带过 |
|---|---|---|
| 单句 | 用词和标点、前后怎么接起来的 | 放在这儿干什么 |
| 几句 | 前后怎么接起来的（重点写几句之间怎么衔接、什么先说什么后说） | 用词和标点只挑 1–2 个 |
| 整段 | 放在这儿干什么、前后怎么接起来的（这段分几步走、谁在说话） | 用词和标点只挑 1–2 个 |

**整段卡在表格上方加一行「这段分几步走」**，用箭头串起来，让读者先看见形状：

```
这段分几步走：起因（2 句，快） → 插一个无关的细节（慢） → 换弟弟来说 → 后果跨几十年（快）
```

每一步一个动词短语，3–5 步。超过 5 步说明该拆成两张卡。单句卡不用这一行，一句话没有步骤。

## 四层怎么看

- **词**：动词、名词、形容词、比喻
- **句**：主要意思在哪、在哪儿停、怎么递进转折重复、什么先说什么后说、节奏
- **段**：这段是开头、推进、转场、举证、反驳、让人物现身，还是收尾
- **篇**：它怎么接住前后章节，怎么改变读者对这个人或这件事的看法

从看得见的文字说起，再说这是什么招。每条解释都要回答「这么选，读起来有什么不一样」。

**四层不必都写满。** 单句卡把前两层写足，整段卡把后两层写足。四层平均用力，每层都会变浅。

## 引用多长

| 摘多长 | 上限 |
|---|---|
| 单句 | 60 字 |
| 几句 | 150 字 |
| 整段 | 300 字，超了用「……」省掉中间，**保留头尾** |

- 全篇引用加起来控制在原文 1% 以内
- 标明章节或页码
- 分清哪句是作者写的、哪句是别人原话
- 背景用自己的话转述，别靠加长引文交代
- 译著第一次出现时注明译者和版本。结构、材料安排、人物和场景的选择可以主要分析作者的决定；中文用词、句子长短、标点和语气写成作者与译者共同形成

整段卡省略中间内容时要**保留头尾**。开头和收尾正是这张卡要分析的地方。

---

## 「我该怎么用」怎么写

写成一个动作，比如「先说这个决定，再压住它造成的后果不说」。举例换一个全新的话题和措辞，别接着原文写。

按用户的水平调粒度：新手给到「把这一句改成……」，有稳定产出的给到「拿你现有的一篇改」。

「什么时候别用」负责提醒：这招在什么情况下会显得煽情、失真、武断，或者一看就是套路。
