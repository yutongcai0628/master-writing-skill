# 画板规范

参考实现：[`assets/board-reference.svg`](../assets/board-reference.svg)。改版前先打开它对照。

## 一条铁律

**视觉结构必须等于信息结构。**

拆解画板呈现七个环节（原文 → 词 → 句 → 段 → 篇 → 学到什么 → 怎么用）。环节之间有明确的先后关系，画面也要按同一顺序展开。中心放射式布局会让四个箭头同时从中心指出，读者无法判断先看哪个——这是旧版最严重的问题。

判断标准：**遮住所有文字，只看形状和箭头，还能说出阅读顺序吗？** 说不出就是布局错了。

---

## 布局：三栏阶梯

```
  原文              四层：词→句→段→篇           方法
┌─────────┐         ┌──────────────┐         ┌──────────────┐
│         │────┐    │ 01 词语与节奏 │────┐    │   可以学的一招    │
│ 一段原文 │    ├───▶│ 02 句法顺序   │    │    └──────┬───────┘
│ 核心段落 │    │    │ 03 段落功能   │    ├───▶        ▼
│         │────┘    │ 04 叙事结构   │────┘    ┌──────────────┐
└─────────┘         └──────────────┘         │   你怎么用    │
                                              └──────────────┘
```

- **一进四拆两出**：左栏一张原文卡进入，中栏四层拆开，右栏汇成方法再落到动作
- **所有箭头同向**（左 → 右，栏内上 → 下）。出现反向箭头就是错的
- **禁止连线交叉**。交叉说明布局错了，改布局，不要改线
- 一进四出用**汇流线**（stub → 竖脊 → 分支），不要画四条独立斜线

中栏四层从上到下是**从词看到篇，越看越大**：词 → 句 → 段 → 篇。用紫色的四阶深浅表达这个递增，颜色负责提示观察范围的变化。

## 色板变量

```
画布
--paper        #FDFBF7      暖白，唯一允许的渐变载体

原文 · 粉（只有那张原文卡用）
--pink-bg      #FCE7EF
--pink-line    #E9A9C0
--pink-ink     #8C3A5C

观察 · 紫（四阶，深浅 = 尺度递增）
--violet-1     #F3EDFB      词语层
--violet-2     #E7DCF7      句法层
--violet-3     #DACAF2      段落层
--violet-4     #CBB6EC      结构层
--violet-line  #9B7FC7
--violet-ink   #4A3566

方法 · 黄（要义 + 迁移）
--amber-bg     #FDF0CC
--amber-line   #E0B44A
--amber-ink    #7A5410

文字
--ink          #3D2E47      主文字，对比度 11:1
--ink-soft     #6B5A78      次文字，对比度 5.8:1
--hair         #E4DCEA      分隔线
```

**色彩语义必须落实**：粉只给原文，紫只给分析，黄只给方法。旧版规范写了这条但实现时乱了（「叙事结构」是黄的、「可以学的一招」是粉的），语义一乱，颜色就退化成装饰。

所有正文对比度 ≥ 4.5:1。马卡龙色只出现在**背景**，文字一律用同色系的深色 ink。

## 字号层级（1600×900 画布）

| 级 | 用途 | 字号 / 字重 | 颜色 |
|---|---|---|---|
| T1 | 画板标题 | 34 / 700 | `--ink` |
| T2 | 副标题 | 17 / 400 | `--ink-soft` |
| T3 | 节点标题 | 20–22 / 700 | 该组 ink |
| T4 | 节点说明 | 14–15 / 400 | `--ink-soft` |
| T5 | 栏目标签、序号 | 12 / 600，字距 .14em | 该组 line |

**字号分成五级。** 旧版只有「节点标题 + 说明」两级，缺少栏目标签这一层，导致三栏之间没有归组感。

## 节点规格

| 节点 | 尺寸 | 圆角 | 描边 |
|---|---|---|---|
| 原文卡（入口） | 400 × 210 | 20 | 2px `--pink-line` |
| 观察节点 | 400 × 92 | 16 | 1.5px `--violet-line` |
| 要义节点 | 400 × 116 | 16 | 1.5px `--amber-line` |
| 迁移节点（终点） | 400 × 150 | 16 | **2px** `--amber-line` |
| 序号徽章 | ⌀34 圆 | — | 实心 line 色，白字 T5 |

- 节点内边距 32px
- 栏内垂直间距 22px，栏间水平间距 105px
- 画布安全边距 90px
- 终点节点描边加粗到 2px——**这是唯一的强调手段**，不要用阴影或放大

## 连线规则

| 线 | 规格 |
|---|---|
| 主链 | 2.5px 实线，箭头 10px |
| 汇流分支 | 2px 实线 |
| 颜色 | 跟随**上游**节点的 line 色（表达"从哪来"） |
| 转折 | 圆角折线，r=16。只在换栏时转折，栏内走直线 |

## 装饰规则

**删掉所有不传递信息的东西。**

旧版四角的圆形色块、左下的曲线——占视觉权重，不传递信息，全部去掉。

唯一允许的非信息元素是画布底的暖白渐变。**留白就是留白，不用色块填。**

## 画布与导出

- **16:9，1600 × 900**
- 用 headless Chrome 按 `--window-size=1600,900` 渲染校对。`qlmanage` 会强制方图并裁掉右栏，不要用它验证
- **飞书画板的缩略图导出（`docs +media-download --type whiteboard`）会把画板补成方形**，下方出现大片空白属于正常现象，与 SVG 本身无关。判断画板是否正确要看内容是否完整、有无被裁切，不要按缩略图的留白去改画布
- 嵌入文档后打开文档确认一次实际渲染

# 第一步的三张画板

拆整本书这一步**以画板为主、文字为辅**。三张，各管一件事：

| 画板 | 画什么 | 布局 |
|---|---|---|
| **一 · 这本书在讲什么** | 中间是全书反复追问的那个问题，四周是它在哪几处被反复验证 | 中心 + 四个出现位置。这里可以用放射，因为它表达的确实是「一个问题，多处取证」 |
| **二 · 章节架构** | 全书分几个阶段、每段怎么推进、章数范围 | 横向时间轴，每段一个色块，下面挂三五个字的特征 |
| **三 · 手法与文风** | 上排 4–6 个反复用的招数，下排文风三项 | 上下两排，上排招数，下排习惯 |

尺寸 1600 × 900，颜色和字号全部沿用上文规范。**画板一允许放射，画板二和三必须单向。** 判断标准还是那条：遮住文字只看形状，能不能说出该从哪儿读起。

画板三的「他从不做的事」要单独留一格——**文风是被这些「不做」定义的**。知道余华从不堆成语，比知道他「语言朴素」有用得多。

# 组画板

一份文档里连续放很多张纯文字拆解卡，读者会读散。用画板调整阅读节奏。

## 画几张：整书三张 + 每组一张

全文画板不设总数上限。整书部分固定三张，第二步每个卡片组配一张。单张卡继续使用表格，避免重复呈现同一份信息。

分配规则：

| 对象 | 配图 | 理由 |
|---|---|---|
| 整书概览 | 3 张 | 分别呈现主旨、章节架构、手法与文风 |
| 第二步的每一组 | 各 1 张 | 画出这一组卡**共用的那套步骤** |
| 单张卡 | 不配 | 卡的证据在文字里 |

## 单句卡不进画板

画板画的是先后和关系。单句卡讲的是用词和造句，没有先后可画，硬画就是凑数。

组画板只从**几句卡和整段卡**里提炼——这两类卡讲的就是什么先说什么后说、哪句翻转了哪句、一段话怎么一步步走完，本来就有步骤。

## 组画板规格

- 画布 **1200 × 560**，颜色、字号和线条全部复用上文规范
- 只画一条动作链，节点 3–5 个，每个节点一个动词短语
- 节点下方可挂一句四到八字的原文碎片作为锚点，不放完整引文
- 用该组主色，延续粉、紫、黄的含义

示例（4.3「把判断压进动作」组）：

```text
给出处境  →  留出沉默  →  极短答复  →  评价留白
「建议带回来」 「停顿1分钟」  「不，修好它」   （作者零形容词）
```

## 卡内的「拆开看」（比小画板更轻）

几句卡和整段卡在正文里加**一行**「拆开看」，纯文本，零成本：

```text
结构：起因（2句·快） → 无关细节（慢） → 交棒见证者 → 后果跨几十年（快）
```

它帮助读者在卡片里快速看见结构。组画板负责概括整组共用的步骤，两者各有一层作用。

## 内容规则

- 画板表达**关系**，正文表达**证据**
- 不在画板里放长引文，一个代表性短例即可
- 每个节点只表达一个动作，说明控制在两行以内
- 终点节点必须落到**当前写作目标下的具体动作**，目标名写进节点标题（「你怎么用｜人物专访」）
- 组内关系较简单时，画板仍需概括整组共同动作；控制在三个节点，避免添加多余说明

## 语言规则

画板文字遵守用户的禁用句式要求，全部采用直接、肯定、动作化的表达。
