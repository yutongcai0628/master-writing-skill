# 飞书文档模板

标题：`《书名》× 想提升的写作类型`

## 一条原则：写给读者看

文档里**不出现我们怎么干活的**。摘取配额、掐一句试试、候选清单打分这些是我们的方法，用户不需要知道，写进去只会让人以为要先学一套东西才能开始读。

判断方法：**这句话是在帮读者学写作，还是在解释我们的流程？** 后者删掉。配额和引用比例这类自查数字，用聊天消息告诉用户。

## 别让用户面对一整屏文字

这是最容易劝退人的地方。硬性要求：

| 手段 | 用在哪 | 要求 |
|---|---|---|
| **表格** | 卡片正文、章节架构、怎么用的清单 | 卡片正文一律用表格，不写成七段话 |
| **高亮框** | 每一组的开头、目标条、练习入口 | 一到两行，说清这一组在讲什么 |
| **画板** | 第一步固定三张，第二步每组一张 | 根据内容需要生成，不设全文总数上限 |

- 一段控制在 3–5 行，超过五行就拆开或改成表格
- 连续两屏纯文字就是排版失败
- 每张卡之间留清楚的空隙

## 篇幅分配

| 部分 | 占比 |
|---|---:|
| 目标条 | 2% |
| 第一步 · 拆整本书 | 25% |
| 第二步 · 拆句子 | 55% |
| 怎么用到你自己的稿子上 | 8% |
| 练一下 | 10% |

## 文档顺序

### 1. 目标条

一个高亮框，两行以内：书名作者、这次要提升什么。不解释方法。

### 2. 第一步 · 拆整本书

四样东西，画板为主、文字为辅：

- **这本书在讲什么**——三五句话说清主旨和全书反复追问的那个问题，配画板一
- **章节架构**——画板二画出全书分几个阶段、怎么推进；后面跟一张覆盖每一章的表格
- **核心写作手法**——画板三，作者反复用的 4–6 个招数
- **作者文风**——并进画板三：句子长短、用词习惯、他从不做的事

章节表按 [`chapter-map.md`](chapter-map.md) 做。

超过 30 章时，正文只放阶段地图和代表章节；完整章节表放在文末附录或单独的飞书子文档，并在正文给出入口。

### 3. 第二步 · 拆句子

按写作动作分组，每组 3–4 张卡。每组的结构固定：

```
高亮框（一到两行，这组在讲什么）
画板（这组卡共用的那套步骤）
卡片 × 3–4
```

每张卡的样子：

```
### 卡 07 ｜ 招数的名字（动作式）
[摘了多长] ｜ 第 X 章 ｜ 作者写的 / 本人说的 / 旁人说的 / 文件材料 / 译者注

> 原文引用

| 前情是什么     | …… |
| 用词和标点     | …… |
| 怎么搭起来的   | …… |
| 放在这儿干什么 | …… |
| 可以学到哪一招 | …… |
| 我该怎么用     | …… |
| 什么时候别用   | …… |
```

原文用引用块，其余全部装进一张表。字段名照 [`close-reading.md`](close-reading.md)。

### 4. 怎么用到你自己的稿子上

一张表。左列动作，右列具体做法。每条都要能今天就做。

### 5. 练一下

一份素材包（不必重开原书就能完成）、一道 8–15 分钟的题、3–4 条自查、一个交作业的入口。素材包用列表，题用有序列表，自查用无序列表。

## 出处怎么标

章节和谁说的直接标在引文旁边。内部候选清单只用来核对，不进正文。用户明确要研究附录时再加来源表。

## 标题层级

- 一级标题：第一步、第二步这样的大块
- 二级标题：分组
- 三级标题：单张卡
- 表格装卡片正文
- 加粗只用在表格外的关键句上，别在表格里再加粗

## 交付前检查

- 有没有连续两屏纯文字？
- 每个字段名能不能对着朋友说出口？
- 有没有先否定一种说法、再转向另一结论的对比句式？顺序颠倒的变体也要检查
- 卡片正文是表格还是段落？段落就重排
