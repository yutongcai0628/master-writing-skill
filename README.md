# 大师写作课 · Master Writing Skill

**给它一本书，它把这本书变成一份能照着练的写作手册。**

你说想提升哪种写作（公众号、小说、人物专访……），它先把整本书拆开给你看结构和文风，再挑出十几段最值得学的原文，一句一句告诉你作者做了什么、你怎么用。

产出是一份飞书文档和一组画板。画板数量跟着全书结构和卡片分组走。

![画板示例](assets/board-reference.png)

---

## 为什么做这个

现在把书变成 AI 技能的工具，做的都是同一件事：**把书压成一个知识库，替你读。**

但读书的人不缺摘要。他缺的是——**读完之后，笔下能多点东西。**

所以这个 skill 不产出读书笔记，它产出的是：这本书的作者在第 3 章第一句用了什么招，这招叫什么，你下一篇稿子怎么用。

## 怎么用

三步。

**1. 装上**

选择你使用的客户端安装：

**Claude Code**

```bash
git clone https://github.com/yutongcai0628/master-writing-skill.git ~/.claude/skills/master-writing-skill
```

**Codex**

```bash
git clone https://github.com/yutongcai0628/master-writing-skill.git ~/.codex/skills/master-writing-skill
```

也可以下载本仓库，再把整个 `master-writing-skill` 文件夹放到客户端的技能目录：

- Claude Code：`~/.claude/skills/master-writing-skill`
- Codex：`~/.codex/skills/master-writing-skill`

装完确认一下 `~/.claude/skills/master-writing-skill/SKILL.md` 这个文件在——**`SKILL.md` 必须直接躺在 skill 目录下**，多套一层文件夹就加载不到。

**2. 把书丢给它**

```
用 master-writing-skill 拆一下这本书 /path/to/book.epub
```

支持 PDF、EPUB、TXT、Markdown。扫描版 PDF 需要先完成 OCR；具体读取和漏章检查规则见 [`references/source-reading.md`](references/source-reading.md)。

**3. 回答两个问题**

它会先问你：

- 你现在写作是什么水平？（完全新手 / 写过一些但不稳定 / 有稳定产出想提升）
- 你想提升哪种写作？

回答完才开始干活。水平决定卡片数量、整理深度和练习难度，写作类型决定它挑哪些段落——同一本书，选「人物专访」和选「公众号深度文」，摘出来的东西会有明显差别。

## 你会拿到什么

### 第一步 · 先拆整本书

以画板为主、文字为辅，因为文字堆太多没人看得下去。

| 拿到什么 | 长什么样 |
|---|---|
| 这本书在讲什么 | 三五句话说清主旨 + 一张画板 |
| 全书分几段、怎么推进 | 一张画板 + 一张覆盖每一章的表格 |
| 作者反复用的五六招 | 一张画板 |
| 他的文风和「他从不做的事」 | 并在同一张画板上 |

章节表**一章一行不跳章**。表里缺章，就说明书没扫完。

「写作看点」那一列只写作者做了什么动作，内容摘要放在前一列：

| 章 | 讲了什么 | 写作看点 |
|---|---|---|
| 序章 | 南非童年的暴力 | 用一个具体营地代替「童年艰难」，主题让场所规则自己说 |
| 30 | 第四次发射成功 | 高潮前用迪士尼排队拖了三次，成功后紧接着写生理反应 |
| 46 | 产能地狱 | 结尾把方法做成一串能截图的清单 |

有些章就是过渡章，那就如实写「功能性过渡，写法上没什么特别」。**允许这么写，不允许每章都吹。**

### 第二步 · 拆具体句子

卡片数量和讲解深度跟着用户水平调整；完成后还会检查全书阶段、主要写法和当前目标有没有空缺。每张卡是一段原文 + 一张表，回答七个问题：

[单句] ｜第 1 章｜作者写的

> 「10岁时，埃隆·马斯克做出了一个决定——一个后来让他深感后悔的决定。」

| 前情是什么 | 本章开篇第一句 |
| 用词和标点 | 破折号把一句话劈成两段，前半给事实，后半给情绪；「决定」重复两次，第二次带定语回来 |
| 怎么搭起来的 | 「深感后悔」提前抵达，具体后悔什么被压住不说 |
| 放在这儿干什么 | 整章的悬念，后面三千字都在还这个债 |
| 可以学到哪一招 | 先说这个决定，压住它造成的后果不说 |
| 我该怎么用 | 写一个人的关键选择时，先给这个选择在他心里的最终定性，内容留到正文 |
| 什么时候别用 | 一篇用一次，用第二次读者就看出套路了 |

## 三条设计上的取舍

**摘取长度分成三种。** 「金句」这个词会把人往格言上带，但很多招数一句话根本装不下——押后说、几个人轮流说、前后呼应、节奏，都得两三句连着看。所以摘取分成单句、几句和整段，还定了配额：单句 ≤30%，几句 ≥40%，整段 ≥25%。交付前会数一遍。

摘到哪儿为止有个土办法：**把前面那句或后面那句掐掉，这个招数还看得出来吗？** 看不出来就往外扩。

**不用大词。** 「声音的组织」「材料换层」「视觉停顿」——这类词得先解释才能懂，读者是来学写作的，不该先学一套行话。检验方法只有一个：**能不能对着朋友说出口？** 说不出口就换掉。SKILL.md 里有一张 20 条的对照表。

**不许堆字。** 卡片正文一律用表格，每组开头放一个高亮框。整书部分固定三张画板，卡片部分每组一张，全文不设画板总数上限。连着两屏纯文字就算排版失败。

## 支持的写作类型

人物专访 · 杂志特稿 · 时尚评论 · 文化评论 · 小红书观点文 · 公众号深度文 · 叙事散文 · 短篇小说

也可以直接描述你的场景，比如「我要写品牌故事」。

指定某本杂志当参照也行，但它只会描述那本杂志看得出来的倾向，不会承诺写得一模一样。

## 关于版权

**不碰盗版，也不需要碰。**

- 书由你自己提供，skill 不去网上找书
- 引用只摘分析必需的部分：单句 ≤60 字，几句 ≤150 字，整段 ≤300 字
- 全篇引用加起来不超过原文 1%
- 每条引用都标章节和出处

拆一本 38 万字的书，实际引用大约 2000 字。分析一段话不需要复制一整本书。

## 已知的限制

**它对书的了解，只来自你给的那个文件。** 涉及作者生平、这本书在文学史上的位置这类需要外部知识的判断，它会标成推测。

**材料撑不起的部分它会说。** 比如书中用于某项判断的材料太少，文风档案里有几栏填不满，它会明说哪几栏是空的，空缺保持原样。

**长书需要更长的处理时间。** 它会先核对目录和完整章节表，再检查开头、中段、结尾及每个重要阶段有没有代表卡片。超过 30 章时，完整章节表放在附录或单独的飞书子文档。

**它不替你写稿。** 每张卡的最后一栏是「我该怎么用」，给的是一个你明天能做的动作。动作还得你自己做。
